## 레퍼런스 사용 시 유의사항
공유된 DAYS ON 페이지는 통합 광고 성과 대시보드로 확인되지만, 공개 페이지에서 실제 수치가 동적으로 로딩되지 않아 성과값은 제안서에 인용하지 않았습니다. 상세 수치가 보이는 캡처나 리포트가 제공되면 해당 값과 기간, 매체 범위를 확인한 뒤 별도 레퍼런스 슬라이드에 반영할 수 있습니다.
